## workflow
### Step1

- choose source and target language. maybe? if necessary?
- user ads either a txt list of words/phrases of a source language OR a CSV with 2 columns (source languge first, then translation)
- TASK: If user only uploaded a list of words, then add the translations.
- Option to add additional translations that have exactly the same meaning, but those translations may be more formal or informal. This option should be a simple, true or false, turn on or off.

### Step2
- Use a Gemini TTS model to generate audio text to speech files for each translation.
- The interface allows to select different voice types and test them before batch generation.

### Step3
- Concatenate all of the audio files together into one long audio file. However, each translation has to be repeated five times in a row. The source language is not needed in the final audio file. For example, the first translation of row number one has to be played five times in a row with a quick break off silence for the listener to repeat, and then afterwards we follow with the next translation. You can find the estimated break between the audio files and the Python source code for generating the final audio.

It must be possible to add a certain translation and replace it with another one, or to even add a new source with translation at a certain row number, or alternatively at the end.
